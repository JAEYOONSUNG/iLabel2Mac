FAQ

Questions, answered

Which label sheets does it support?

All 1,006 official iLabel formats from label.kr are built in, and you can define fully custom sheet geometry or roll labels when your stock isn't in the catalog.

I was using iLabel2Mac. Do my projects still open?

Yes. iLabel Studio is the same app renamed — quit the old iLabel2Mac, install iLabel Studio, and remove the old bundle. Existing projects and preferences remain compatible.

Are projects portable between Mac, Windows, and Linux?

Yes. Every edition shares one project format, including rich text, embedded fonts, merge data, numbering, placement, and captured print queues.

How does printing on a partially used sheet work?

Stage empty positions in Page Preview, then capture the run. The capture queue remembers which cells are gone, so the next run starts exactly where the last one ended.

Does it cost anything?

No. Download it from GitHub and print.
